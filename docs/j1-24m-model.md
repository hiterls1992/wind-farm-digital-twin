# 06B1-J1，24 m 呼高模型

依据：JNHY-2024-14-021Z-L0202 J1杆塔竣工图，2025.03。总图01、上横担02、下横担03、塔头04及塔身05–07。

仅生成24 m呼高：全高30.70 m、根开4.372 m、顶宽0.400 m。下横担标高24.00 m，左右挂点距塔中心线2.550 m；上横担标高27.60 m，单侧距中心线2.000 m。横担根部高度分别1.30 m和1.00 m。

塔脚0–3 m采用人字撑，3–6 m过渡段，6–12 m及12–18 m塔身，18–24 m上塔身，24–30.70 m塔头。塔宽按结构节点分段插值，主材在变坡节点断开重接。保留角钢L形截面、四面斜撑、主要横隔和空间横担。省略螺栓、孔洞、小连接板，局部辅助材布置与规格按展示用途归并简化，不作为加工模型。

绝缘子为场景附属示意，3片悬垂串尺寸沿用项目配置，并非结构图确认的电气金具选型。导线挂点从绝缘子下端统一派生。场景已有显示倍率会整体放大模型，不改变模型本身米制尺寸。

代码：js/tower-j1.js；主场景index.html直接使用该模型。旧独立演示HTML及旧典型GLB生成器不是此次图纸模型来源。
