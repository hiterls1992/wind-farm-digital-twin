# 场内新建道路

输入：风场数据/道路.dxf，12条LWPOLYLINE，98个顶点，无圆弧凸度。按道路中心线处理，每侧扩宽3米。坐标为CGCS2000、3度带38带、中央经线114E、不含带号的东坐标。DXF头部INSUNITS为1（英寸），与工程坐标数量级不符；本次依据与机位一致的坐标范围按米解释，未做英寸缩放。

命令：python src/import_roads.py，然后 python src/run_pipeline.py --offline。

输出data/roads.json，包含经纬度路径、宽度、路面做法及长度统计。前端使用6米实际宽度的Cesium贴地走廊覆盖卫星影像，以山皮石灰褐色表示；不使用像素线宽，不受风机或杆塔倍率影响。原最小生成树示意道路已移除。路面为材质示意，未模拟石料颗粒或路基开挖。
