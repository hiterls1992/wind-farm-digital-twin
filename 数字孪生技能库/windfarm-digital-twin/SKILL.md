# 风场数字孪生总控

目标是基于用户替换的输入文件创建新项目，而不是复制旧工程数据。此包包含可执行模板和初始化脚本；当前项目不受影响。读取 [数据契约](references/data-contract.md)，填写 [项目配置](references/project.config.example.json)。同结构同坐标同线路规则的项目只需替换输入及名称；跨坐标或不同拓扑需同步配置，格式变化由相应模块适配，不能承诺任意文件零配置。

## 创建流程

1. 检查输入表头、单位、行数、坐标基准和线路连通资料；确认新项目目录。配置中null表示可选模块缺失，界面应明确暂无数据，不制造示意实测值。
2. 复制配置样例到用户工作目录，填项目名/位置、坐标带号、文件名及线路chains/links。地图密钥单独提供，不从旧项目复制。
3. 运行 `python scripts/new_project.py --target <全新目标目录> --config <配置JSON> --input-dir <输入文件目录>`。命令相对于本技能目录；目标存在则停止，避免混入上一项目的缓存。
4. 在目标目录安装requirements后运行 `python src/run_pipeline.py --prepare`；再运行 `--fetch-dem` 采集当前场址地形并打包。已验证同原点DEM时可用 `--offline` 仅打包。DEM需要网络并有断点缓存，勿把旧DEM带入新项目。
5. `python -m http.server 8123 --bind 127.0.0.1` 启动，在浏览器打开实际地址。禁止把静态语法检查当场景验收。
6. 按模块验证数据、样式和交互；报告实测/推断/估算与尚未验证事项。保存输入和配置即可复现。若超出模板支持范围，先适配导入器再生成，不能静默修改数据语义。

## 边界

包内libs/cesium为已有Cesium1.118发行资源，保留随包版权文件；其他服务仍需遵守各自许可。不含原项目输入表、原始PDF、DEM、私密配置或截图。J1/SJ1外观例子可选复用，实际设计需新项目图纸确认。技能文件没有自动安装到全局；用户可直接指定本SKILL.md路径调用，或把整组技能放到其技能搜索目录以保留兄弟依赖。

已完成与未完成的验证见 [验证记录](references/validation.md)，不要把它扩写为浏览器或联网验收通过。

## 风机参数工作表

风机Excel可增加“风机参数”表（由sheets.machine配置），三列为分组/参数名称/值；合并单元格分组向下继承，首行“项目”对应机型名称。用src/import_machine_parameters.py在机位导入后处理，输出machine.model、machine.parameters.items及参数来源，页面“场址总览”展示全部规格，标签可显示机型。
叶轮直径优先级：明确项目配置/用户覆盖 > 参数表，保留rotor_d_source_m与rotor_d_override_m并提示差异；不能用新表静默覆盖用户明确指定。额定容量与电量表不符时报错，不静默重算历史电量。轮毂高度仍取逐机资料；扫风面积、切出风速范围、温度、发电机型式等保持原表值和单位，不能把区间解析成一个值，也不把扫风面积强制改成圆面积。混装机型需扩展逐机参数映射。

## 当前模板版本

参数表驱动叶轮直径，配置null表示使用表内值；所有近期界面修改已同步到assets/project-template，不仅更新说明。页面无待扩展卡片；默认停止叶轮、隐藏场区边界及无位置的升压站。能量页按模块展示，逐时功率有独立月份刻度时间轴和叠字功率柱，总功率位于标题栏。新项目仍须按数据契约配置坐标、拓扑及参数来源，不能直接复制旧项目覆盖值。
